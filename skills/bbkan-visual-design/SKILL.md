# BBKan Visual Design

The style is called **纸窗蓝 (BBKan Paperframe)**, named for its paper-like surfaces and deep-blue window frames.

Apply the visual language of 不白看 to a new design while keeping the result useful for its audience, content, and medium. The style combines warm editorial paper with compact retro-computer details: considered typography, restrained color, square geometry, crisp rules, and physical-looking borders.

## Choose the medium

- For a website, read [references/web.md](references/web.md).
- For a poster, read [references/poster.md](references/poster.md).
- For work spanning both, use the shared design principles below, then read both references and keep the visual identity consistent across screen and print.

Use [assets/bbkan-theme.css](assets/bbkan-theme.css) as an optional starting point for web CSS. Adapt it to the project's stack instead of replacing an existing design system wholesale.

## Shared design principles

- Start with warm paper (`#F1EEE5`), an off-white panel (`#FFFCF5`), and dark ink (`#222923`). Use deep blue (`#17439A`) for the main frame or navigation and orange (`#F26A32`) for a small number of useful accents.
- Keep the palette disciplined. Blue carries structure; orange marks one action, annotation, or moment of emphasis. Avoid using every brand color with equal weight.
- Pair a readable Chinese sans-serif with a restrained monospaced face for labels, indexes, metadata, and short technical details. Use available fonts and provide sensible fallbacks.
- Favor firm edges, square or minimally rounded corners, thin rules, and short hard shadows. Inset light and dark edges can suggest a pressed-paper or old desktop control; reserve this treatment for elements that benefit from physical tactility.
- Build hierarchy from scale, weight, alignment, spacing, and contrast before adding decoration. Let the content lead.
- Use the paper and interface motifs as a design vocabulary, not as literal nostalgia. Avoid clutter, fake scanlines, gratuitous noise, and ornamental controls that do not serve the content.
- Preserve legibility, keyboard access, responsive behavior, and the intended output size. The visual style never overrides those needs.
- Do not reproduce the BBKan logo or imply that an unrelated project is an official 不白看 product unless the user asks for that branding.

## Working approach

Identify the audience, content, action or takeaway, and delivery medium. Choose a hierarchy and layout that serve them, then apply the relevant reference. If a required detail is missing, make a modest reversible assumption and state it briefly. Check the result at its actual viewport or print dimensions, including text legibility and contrast.
