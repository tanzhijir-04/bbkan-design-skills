# Poster design reference

Use this reference for print or digital posters in the BBKan visual style.

## Plan the information

Before placing elements, identify the event, subject, or message; the one detail viewers should remember; essential logistics; and the intended viewing distance. Set the title, supporting line, details, and credit in a clear reading order.

## Compose

- Use a paper ground, ink typography, one dominant blue structural area, and a restrained orange highlight. Leave enough quiet space for the main message to register.
- Choose one focal point: a large title, a single strong image, or a bold piece of information. Do not make every element equally loud.
- Use grid alignment, crisp rules, small monospaced labels, and firm rectangular frames to evoke editorial print and desktop chrome.
- Keep essential event details together and easy to scan. Place date, time, venue, and call to action where viewers expect them.
- Use paper texture or halftone sparingly. Preserve contrast behind all text; do not generate text inside raster artwork when it can be typeset cleanly.
- Let the palette support the message. Orange is an accent, not a second background color competing with the blue.

## Size and output

- Confirm orientation, finished dimensions, bleed, safe area, and color requirements with the printer or publishing platform. If they are unknown, state a practical assumption in the handoff.
- Design at the final aspect ratio and inspect at both full size and thumbnail size. Essential copy should remain readable at the expected viewing distance.
- Keep type and logos as vector or live text where possible. Use sufficiently high-resolution raster imagery for the final size.
- For print, export to the printer's requested PDF profile and include bleed only when requested. For social use, export a separate pixel-sized version rather than relying on a print PDF preview.
- Check line breaks, edge clearance, contrast, and all event details in the exported file before delivery.
